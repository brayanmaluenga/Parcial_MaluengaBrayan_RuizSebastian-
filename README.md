# La Última Transmisión

Proyecto desarrollado en Python para el parcial práctico.

## Descripción

Juego narrativo interactivo basado en escenas, decisiones del jugador, condiciones booleanas y múltiples finales.

## Tecnologías

- Python
- Git y GitHub
- Trello para la metodología Kanban
- Pruebas automatizadas con unittest

## Estructura

- `src/`: código fuente.
- `data/`: archivos de historias y escenas.
- `tests/`: pruebas automatizadas.
- `docs/`: documentación.
- `evidencias/`: capturas y evidencias del desarrollo.
